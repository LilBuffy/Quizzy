# 🎮 QUIZZY

**QUIZZY** is a fucking modern online quiz platform designed for classrooms, competitions, and interactive learning.

Teachers can create and manage quizzes, while participants can join instantly using their name and a quiz code without creating an account.

Basically:

**Teacher creates quiz → gets code → participants join → answer questions → abuse powerups → leaderboard decides who wins.**

Simple. Competitive. Slightly chaotic. **Blyat.**

## 👨‍🏫 Teacher Panel

Teachers can:

* Register and log in
* Create, edit, and delete quizzes
* Generate quiz codes
* Create and manage questions
* Set correct answers and points
* Configure timers and quiz settings
* Enable or disable powerups
* Start and close quiz sessions
* Monitor participants
* View leaderboards
* View quiz statistics and performance

## 👤 Participant System

Participants don't need an account.

They can:

* Join using their name and quiz code
* Answer questions
* Use the countdown timer
* Track their progress
* See their live score
* Use powerups and boosts
* View their final score
* View their ranking
* Check accuracy and performance

No registration.

Just enter the code and **go fucking fight.**

## ⚡ Powerups

QUIZZY includes several powerups:

* Double Points
* Fifty Fifty
* Time Boost
* Shield
* Score Boost

Powerups and scores are validated on the server so participants can't simply open DevTools and start giving themselves 999999 points like some **pizdets hacker**.

## 🏆 Leaderboard

The leaderboard provides:

* Live rankings
* Participant names
* Scores
* Correct answers
* Ranking and tie handling
* Competitive scoring

Basically, the part where everyone discovers who is actually smart and who was just **guessing with confidence, blyat.**

## 🔐 Security

The system includes:

* Secure teacher authentication
* Password hashing
* PDO prepared statements
* CSRF protection
* XSS protection
* IDOR protection
* Server side scoring
* Server side timer validation
* Quiz code protection
* Duplicate submission prevention
* Rate limiting
* Session security

Because letting participants modify their own scores would be **absolute govno**.

## 🧹 24 Hour Data Cleanup

Temporary participant records, quiz session data, answers, and results are automatically removed after **24 hours**.

Teacher created quizzes and questions remain until manually deleted.

Less useless data.

Less database **govno**.
